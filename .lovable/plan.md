修正頭像調整觸控操作：

1. 改用更穩定的 Pointer Events 管理手指操作
   - 單指拖曳：直接移動照片位置。
   - 雙指捏合：同時縮放與移動照片。
   - 最大縮放維持 2 倍。

2. 補強行動裝置相容性
   - 避免 Dialog 或瀏覽器捲動攔截手勢。
   - 在觸控區域強制 `touch-action: none`、`overscroll` 控制。
   - 不依賴可能在手機上失效的 React touch 事件狀態同步。

3. 保持現有介面不變
   - 不加入 `+ / -` 按鈕。
   - 不顯示操作說明小字。
   - 中間圓形框維持所見即所得，確認後輸出同一個圓形裁切結果。
